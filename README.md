# Custom Capacities

A Dusklight mod that allows you to customize the capacities of Wallets, Bomb Bags, Quivers and Slingshot Pellets.  
More information on the mod page: [https://twilitrealm.dev/mods/com.darkzant.custom_capacities/](https://twilitrealm.dev/mods/com.darkzant.custom_capacities/)

Uses the [Dusklight mod template](https://github.com/TwilitRealm/mod-template) for [Dusklight](https://github.com/TwilitRealm/dusklight) mods.
